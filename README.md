# HTML för nybörjare
__HTML__ används för att skapa och strukturera innehåll på webbsidor

## Hur man börjar
Ladda ner VS Code 'länk till visual studio code'

Ladda ner Live server via VS Code 'bild på install'

`! 'tab'`

## Vanliga element:
- DOCTYPE=Hur dokumentet är byggd
- Head=innehåller osynlig information
- html=omsluter hela dokumentet
- title=Bestämmer texten på webbläsarens flik
- body=Innehåller allt synligt innehåll
- h1=rubrik
- p=paragraf

Till exempel kan ett __HTML__ dokument se ut såhär:

```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-widthinitial-scale=1.0">
    <title>Min webbplats</title>
</head>
<body>
    <h1>Välkommen till min webbplats!</h1>
    <p>Detta är min första webbsida.</p>
</body>
</html>
```

## "Välkommen till min webbplats!"
"Detta är min första webbsida."

## Rätt tecken
Element öppnas med `<tagg>` och stängs med `</tagg>`.
